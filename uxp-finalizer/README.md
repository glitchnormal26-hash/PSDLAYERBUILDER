# Photoshop UXP Finalizer

This optional Photoshop plugin is the native-rendering last mile for PSDs produced or modified by PSDLAYERBUILDER.

## Why it exists

The portable Node engine can author PSD structure, embedded sources, masks, effects and projective caches without Photoshop. Some Photoshop-only behaviors—custom warp rendering, Smart Filters, exact text rasterization and other native caches—are best regenerated by Photoshop itself.

The finalizer:

1. finds Smart Object layers in the active document;
2. attempts Photoshop's **Update All Modified Content** action for linked content;
3. opens each Smart Object through Photoshop, saves its contents and closes it so Photoshop refreshes the parent cache;
4. saves the parent PSD;
5. reports per-layer failures instead of aborting the entire document.

## Load for development

Use Adobe UXP Developer Tool and add this `uxp-finalizer` folder as a plugin. The manifest uses v5 and requires Photoshop 23.3 or newer. It does not request arbitrary filesystem access.

You can run it from the plugin panel or the `Finalize PSDLAYERBUILDER Mockup` command.

## Production recommendation

Use the Node `replace` / `replace-many` workflow first, open the generated PSD in Photoshop, then run this finalizer before delivery when the template contains custom warp, Smart Filters, advanced text, or other Photoshop-native rendering behavior.
